# Inspiration

This directory holds material that influenced wikiactive. These documents do
not describe wikiactive. The wikiactive design is in
[`../design-plans/`](../design-plans/) and [`../decisions/`](../decisions/).

## wikiharness

[`wikiharness/`](wikiharness/) is a copy of a private workspace of ideas about
LLM-assisted, human-confirmed improvements to Wikipedia, Wikidata, and Commons.
It contains design documents, decision records, analyses, and blog drafts,
dated between 2026-06-01 and 2026-09-13.

Everything in the workspace is very incomplete. Read it as work in progress,
not as ground truth.

- An LLM wrote much of the text during working sessions. An evaluation or a
  plan in these files is not necessarily the opinion of the repository owner.
- The designs were not built as written.
- A statement about another project describes that project on the date of the
  document. That project may have changed after that date.
- The files in `wikiharness/blog/` are drafts.
- Some links point to files that are not in this copy.

The copy comes from the tracked `README.md`, `blog/`, and `docs/` of the
workspace at commit `2c816f8` (2026-09-13). The copy does not include these
parts of the workspace:

- the agent configuration files
- the collaboration notes and two analyses of other projects
- the publication plan and the drafting notes for the blog series
