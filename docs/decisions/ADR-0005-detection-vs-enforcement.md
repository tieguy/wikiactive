# ADR-0005: Detection vs enforcement — the base-article scan detects; only drafted lines enforce
Status: Accepted (2026-10-01)
Context: The linter corpus can run over any wikitext, but the loop has two different relationships to defects: defects in the BASE article are other people's (or earlier rounds') work; defects in lines THIS TOOL drafts are ours. The linter has encoded drafted-lines scoping since the rule-enforcement plan; loop-mechanization Phase 6 added a detection surface (the analyze bundle's base-article defect candidates).
Decision: The two scopes are permanently distinct. The analyze bundle's defect scan DETECTS base-article mechanical defects as candidate assessments — informational, clearly labeled, nothing auto-applies, and no gate reason can originate from it. The gate ENFORCES only on lines this tool drafts (`rules/linter.toml` `scope = "drafted-lines"`): pre-existing defects never block, newly drafted defects always do.
Alternatives considered:
- Whole-page enforcement (gate on every defect found anywhere) — rejected: the tool would block publishing its own scoped edit because of a stranger's semicolon; enforcement would be a denial of service on any imperfect article.
- Let the scan feed the gate as advisory reasons — rejected: a reason-shaped thing that does not block is noise in a report whose value is that every line is actionable; candidates belong in the judgment context (the bundle), where the assess step weighs them.
- No base-article detection at all — rejected: the corpus already sees these defects; hiding them wastes mechanical signal the assess step can use (e.g. L2/L3 loops fixing citation formats).
Consequences: The scan's output shape (severity, rule, line, description) is candidate material, never a verdict; the drafted-lines pins (linter suite) and the detection-only pin (rules corpus suite) both stay green. New linter rules declare their scope explicitly; a rule that should gate base text as well as drafted text is a new decision, recorded here as a superseding record.
Open questions: the five surveyed prior-art linter rules (docs/2026-09-30-linter-prior-art.md §3) remain deliberately unbuilt; when taken up, they slot into this same detection surface.
