## Decisions (locked)

- **Assessment ids:** `AS<n>` — `is_numbered_id` generalizes to a `&str`
  prefix (`"AS"`, `"Q"`). JSON record shape: `{"assessments":[…]}` in
  `assessments.json`. Field names inside each record are unchanged in this
  phase (`wikitext_anchor`, `rules`, `evidence`, `factual_note`,
  `proposed_fix`, `loop`).
- **Retired command arms:** hidden clap variants (`Findings`, `Sweep`,
  `Check`, `Review`) with `trailing_var_arg` rest-args that always
  `anyhow::bail!` with a pointer to the replacement. They never dispatch.
- **`wa fetch` shape:** `Command::Fetch { slug: Option<String>, wikitext:
  Option<PathBuf>, cmd: Option<FetchCmd> }` with
  `subcommand_precedence_over_arg = true`; `FetchCmd::{Dispose,Status}` carry
  their own `slug` positional. No subcommand ⇒ inventory-then-fetch using the
  parent slug (error with usage if absent). Behavior pinned by tests; if
  clap's precedence misbehaves, fallback = make `Run` an explicit hidden
  subcommand and keep `wa fetch <slug>` working via clap alias — decide by
  test evidence, not preference.
- **`wa audit` Phase 1 shape:** `Command::Audit { slug, #[arg(long)] llm: bool }`.
  No `--llm` ⇒ today's `check_cmd` body (gate preflight, no artifact);
  `--llm` ⇒ today's `review_cmd` body (rule-review pass). `wa render`/`wa
  poll` untouched this phase. Output wording: "audit" replaces "check" in
  user-facing strings ("no artifact written by audit").
- **Serve:** routes rename `/driver/findings`→`/driver/assess`,
  `/render`→`/audit`; "Write findings"→"Assess", "Render review"→"Audit".
  The Audit form gains an unchecked `llm` checkbox ("LLM diagnosis");
  when set, the audit POST runs the existing `run_rule_review` after a
  successful render, before redirecting. The standalone "Check against the
  rules" bar control in `inject_comment_ui` is REMOVED (results display
  stays). Round-log phase string stays `"rule-reviewed"` (on-disk history).
- **Module/serde names:** `src/sweep.rs` module name, `sweep_status` ledger
  field, `register_sweep_source`, `sweep_unresolved`, `SweepConfig`,
  `rules/sweep.toml`, `rules/sweep.toml` fixtures — all unchanged (serde
  compatibility with committed ledgers).
- **Prompt rename:** `prompts/author-findings.md` → `prompts/assess.md`;
  const `ASSESS`; wording findings→assessments, `F<n>`→`AS<n>`,
  `{{max_findings}}`→`{{max_assessments}}`; `FindingsContext`→`AssessContext`
  (field `max_findings`→`max_assessments`); step fn `author_findings`→
  `assess`; step-name strings `"author_findings"`→`"assess"`;
  `propose.md` "no F or Q numbers" → "no AS or Q numbers". Both checksum
  pins updated, reason in commit message.
- **zai fixtures:** renamed to `assess.request.json`/`assess.response.json`
  (plus `.headers`), `scripts/zai-spike.sh` updated to the new names and the
  AS-schema request wording. Refresh via live `./scripts/zai-spike.sh` only
  if `ZAI_API_KEY` is in the environment; otherwise defer to the operator
  (documented in the final report) — never hand-edit captures.
